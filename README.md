# 1485-concept

The 14.85 Concept Limited architecture and engineering website, built with Next.js 14, TypeScript, Tailwind CSS, and GSAP.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Production build

```bash
npm run build
npm run start
```

Copy `.env.example` to `.env.local` and configure the site URL and SMTP settings before enabling live RFQ email delivery. Keep `.env.local` out of version control.
